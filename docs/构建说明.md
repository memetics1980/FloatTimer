# 构建浮光计时 1.0.22

## 环境

Windows 10 / 11，使用系统自带的 Windows PowerShell 与 .NET Framework 4.x。无需安装 .NET SDK 或下载依赖包。

## 目录

```text
src/FloatTimer/
  FloatTimer.cs          窗口、计时引擎、分组、持久化与内置自检
  AudioSettings.cs       WAV/MP3 导入、格式校验、音色选择与逐段声音
  build.ps1              构建脚本
  app.manifest           标准用户权限、Windows 兼容性和 DPI 声明
  快速使用指南.txt        构建时复制的使用说明
  assets/
    desk-bell.wav        内嵌前台铃
    音频来源.txt          前台铃说明
docs/                    完整说明与打印指南
```

## 构建

在仓库根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\src\FloatTimer\build.ps1 -OutputDirectory .\dist\FloatTimer
```

脚本会生成图标，调用 Windows 的 .NET Framework C# 编译器，编译两个 C# 源文件并内嵌音频资源。输出目录包含程序及快速指南。

## 计时逻辑自检

```powershell
$exe = (Resolve-Path .\dist\FloatTimer\FloatTimer.exe).Path
$report = Join-Path (Split-Path $exe) 'self-test.txt'
$process = Start-Process -FilePath $exe -ArgumentList @('--self-test', ('"' + $report + '"')) -Wait -PassThru
Get-Content -LiteralPath $report
if ($process.ExitCode -ne 0) { throw '自检失败' }
```

自检覆盖倒计时、正计时、暂停、继续、重置、完成状态、持久化及无效设置归一化。正式比赛前还应在实际输出设备上试听提示音。

## 配置和音频

程序的所有组、布局和计时设置保存在运行目录的 `FloatTimer.settings.json`。自定义音频存入设置文件，文件导入后不依赖原路径。该文件属于用户个人配置，已在 `.gitignore` 中排除。

WAV 使用本应用的 Windows 音频会话播放；MP3 使用 Windows 原生多媒体接口播放。切换提示音、重置或退出时会停止旧声音并清理资源。单个自定义文件限制为 10 MB、120 秒。
